# Car Dealership Manager Tycoon

A standalone, playable browser version of **Car Dealership Manager Tycoon**.

## Play

Open `index.html` in a modern browser. The game is offline-first and stores the save locally in your browser.

For a local development server:

```bash
npm install
npm run dev
```

Then open the local URL shown by the server.

## Current playable systems

- Dealership dashboard and progression
- Dynamic fictional vehicle market
- Vehicle purchasing and transport costs
- Inspection, repair and detailing
- Inventory capacity
- Customer generation and archetypes
- Interactive negotiation and sales
- Staff hiring and training
- Dealership upgrades
- Reputation
- Market events
- Loans and operating costs
- Time progression
- Transactions and financial reporting
- Expansion to other locations
- Achievements
- Local save/load and reset
- Responsive desktop/mobile UI

## Notes

This build intentionally uses no external runtime APIs or paid assets. The game logic is contained in `index.html`, so it can be played locally or hosted as a static site.

The master specification remains included in the repository as the product design reference.
